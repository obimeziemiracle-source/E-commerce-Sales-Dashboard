## E-commerce-Sales-Dashboard

## Project Overview
This project analyzes e-commerce sales data with the use of Power BI to identify sales trends, customer behaviour, regional performance, and product category performance.

## Objective
To analyze sales data and to provide insights into customers purchasing behavior, discounts, product categories, and monthly sales trends to support business decision-making.

## Tools Used
-Power BI
-Microsoft Excel
-SQL

## Dashboard Features
-Total Sales
-Total Profit
-Total Customers
-Sales by Region
-Sales by Category
-Top Customers
-Monthly Sales Trend

## Key Insights
-Furniture generated the highest profit.
-The South West regionrecorded the highest sales.
-Office Supplies recorded the highest sales.
-September recored the highest monthly sales.

## Recommendation
-Increase inventory for high-demand product categories.
-Investigate ways to improve the profitability of lower-performing categories.
-Focus marketing effort on high-performing regions.
